# 牛顿环 · 学生实验平台

学生访问网址：https://hwangbl.github.io/newton-rings-lab-students/

本仓库保存学生网站的压缩发布文件、教学图片，以及针对公开发布版本的兼容性修复和回归测试。原始开发工程、原工程的测试与构建脚本仍保存在教师私有仓库中。这里不提供完整课件、参考论文或评分文件的下载。

网页运行所需的 HTML、CSS 和 JavaScript 会公开发送到浏览器。压缩构建并不使前端算法成为秘密。

图片分析和实验数据处理均在学生浏览器本地进行。图片不会上传；已有读数可通过 CSV 导出和导入。新网址不会自动继承旧网址的本地学习记录。

新导出的读数 CSV 会同时保存数据来源、影像标定和计算参数。重新导入影像等效坐标时，仍显示“影像不确定度未评定”，不会将其当作独立显微镜读数。旧版三列 CSV 继续支持，但没有来源信息的旧文件无法自动恢复影像/模拟标记；影像数据应从“图像分析”重新送入。

维护者可查看 [公开版本修复说明](maintenance/README.md) 和 [压缩文件修改对照](maintenance/bundle-changes.md)。静态网站仍可直接打开 `index.html`，运行网站不需要 Node.js 或安装依赖。
